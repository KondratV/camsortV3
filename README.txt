camsort (V3)

Скрипт для сортировки видеозаписей по датам и временным интервалам.

Сканирует входной каталог, из имени файла извлекает дату и время начала записи,
создаёт в выходном каталоге подпапку ГГГГ-ММ-ДД и копирует туда файлы,
попадающие в заданные временные интервалы и разрешённые белым и/или чёрным списком дней.

Исходные файлы не удаляются и не перемещаются.

ТРЕБОВАНИЯ

Python 3.8+
Только стандартная библиотека (внешние зависимости не нужны)

УСТАНОВКА

Ничего устанавливать не требуется. Скопируйте папку и запускайте скрипт.

НАСТРОЙКА КОНФИГА

1. Скопируйте config_example.txt в config.txt:
   Windows:      copy config_example.txt config.txt
   Linux/macOS:  cp config_example.txt config.txt

2. Отредактируйте config.txt (открывается блокнотом).
   Строки, начинающиеся с ;, — комментарии, их можно не трогать.
   Правятся только значения после знака =.

3. Запуск:

   Перейдите в папку со скриптом:
   cd C:\путь\до\cam-sort

   Запустите:
   python cam_sort.py -c config.txt

   Если python не найден, используйте py:
   py cam_sort.py -c config.txt

ПАРАМЕТРЫ config.txt

Все параметры — в секции [settings], формат: ключ = значение.
Строки, начинающиеся с ;, — комментарии.

src_dir — путь к входному каталогу с исходными записями. Менять обязательно.

dst_dir — путь к выходному каталогу, внутри создаются подпапки ГГГГ-ММ-ДД. Менять обязательно.

filename_regex — regex с группами date и time; по умолчанию: ^(?:.*?)_(?P<date>\d{8})(?P<time>\d{6})_\d{14}_\d+\.mp4$. Не менять, если формат имён не менялся.

date_format — %Y%m%d, %Y-%m-%d, %d.%m.%Y, %Y_%m_%d. Не менять, если формат имён не менялся.

time_format — %H%M%S, %H-%M-%S, %H:%M:%S. Не менять, если формат имён не менялся.

intervals — интервалы через запятую, формат ЧЧ:ММ-ЧЧ:ММ, границы включительно.
Пример: 09:00-10:00, 11:00-12:30, 15:00-17:00

whitelist — белый список: даты через запятую, формат ГГГГ-ММ-ДД.
Поддерживаются диапазоны: 2026-10-12..2026-10-16.
Пусто — берутся все дни. Если задан — берутся только дни из него.

blacklist — чёрный список: даты через запятую, формат ГГГГ-ММ-ДД.
Поддерживаются диапазоны: 2026-10-12..2026-10-16.
Пусто — ничего не исключается. Применяется после белого списка.

day_type — all, weekdays, weekends. Применяется до белого/чёрного списков:
all — без фильтра, weekdays — только пн–пт, weekends — только сб–вс.
Праздники РФ не учитываются — добавляйте их в blacklist вручную.

Если заданы оба: сначала применяется белый список (остаются только его дни),
затем из результата вычитается чёрный.

overwrite — false, true. Если файл с таким именем уже есть в папке назначения:
false — пропустить, true — перезаписать.
