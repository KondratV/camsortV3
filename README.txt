camsort V3 (скрипт)

Сортировка видеозаписей по датам и временным интервалам.
Копирует файлы из входного каталога в подпапки ГГГГ-ММ-ДД,
фильтруя по времени и по дням (белый/чёрный список, будни/выходные).
Исходные файлы не удаляются и не перемещаются.

ТРЕБОВАНИЯ

Python 3.8+. Только стандартная библиотека, внешних зависимостей нет.

ФАЙЛЫ

camsort.py          — логика сортировки (CLI)
camsort_gui.py      — графический интерфейс для настройки и запуска
config_example.txt  — шаблон конфига, все параметры с комментариями
config.txt          — рабочий конфиг (создаётся из шаблона, в git не входит)
README.txt          — этот файл

ЗАПУСК

GUI:
  python camsort_gui.py

CLI (без GUI):
  python camsort.py -c config.txt

Если python не найден — используйте py вместо python.

КОНФИГ

GUI хранит настройки в %APPDATA%\camsort\config.txt и пишет их сам.
Для CLI: скопируйте config_example.txt в config.txt и отредактируйте.
Все параметры и допустимые значения — в комментариях внутри config_example.txt.
